## 英雄進化

**萬木之王　SR・綠・英雄進化（5）｜由林海之王進化**
- 英雄 HP 上限 +8
- 多一個被動「萬木」：我方生物HP 上限 +1
- 每局只能進化一次

**烈焰君王　SR・紅・英雄進化（6）｜由烈焰領主進化**
- 英雄 HP 上限 +6
- 天生技換成 煉獄（2）：〔任意目標〕造成 3 傷害
- 每局只能進化一次

**無名劍聖　SR・白・英雄進化（6）｜由無名劍士進化**
- 英雄 HP 上限 +7
- 天生技換成 劍意（2）：〔我方生物〕目標攻擊 +2
- 每局只能進化一次

## 進化線

- 焰尾狐（N） → 焰狐王（R） → 九尾天狐（SR）
- 林地蠻熊（R） → 森林熊王（SR） → 古樹熊神（UR）
- 見習騎士（N） → 聖騎士（R） → 熾天使（SR）
- 小水母（N） → 雷光水母（R） → 深海水母皇（SR）
- 骷髏兵（N） → 骷髏騎士（R） → 死亡騎士（SR）
