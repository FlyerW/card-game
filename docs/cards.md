# 範例卡牌

> 這份文件由 `npm run cards` 從 [`packages/engine/src/cards/sample.ts`](../packages/engine/src/cards/sample.ts) 產生，

## 英雄進化

**萬木之王　SR・綠・英雄進化｜能量 5｜由林海之王進化**
